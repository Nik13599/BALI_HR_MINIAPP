# BALI production E2E matrix

Дата проверки кода: 2026-07-30.

Обозначения:

- `AUTO` — сценарий покрыт исполняемым server/security/integration-тестом.
- `CODE` — серверная схема, API и/или UI реализованы и проходят статические проверки, но нужен прогон на staging PostgreSQL.
- `DEVICE` — необходима ручная проверка на реальном Telegram-клиенте или указанной ширине экрана.
- `BLOCKED` — невозможно подтвердить без внешней среды или production-данных.

## Release gate

Выпуск запрещён, пока не выполнены все строки `DEVICE` и `BLOCKED`, не пройден
конкурентный тест бронирования на настоящем PostgreSQL и не проверены backup/restore.
